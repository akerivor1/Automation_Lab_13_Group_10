
# הוראות הפעלה למערכת הקלפי

מערכת חכמה לניהול כניסה ויציאה של מצביעים בקלפי, המבוססת על בקר Arduino Uno.

## הוראות הפעלה

| שלב | מי מבצע | מה לעשות |
                                                                                                                                                         |---|---|---|
| **1. הפעלה** | מפעיל המערכת | ודאו שהשער סגור. חברו את בקר הארדואינו באמצעות כבל USB והמתינו להודעת `SYSTEM READY` במסך. |
| **2. המתנה לכניסה** | מצביע | עמדו מול חיישן הלייזר שמחוץ לקלפי, במרחק 8 עד 50 ס"מ, והמתינו לפתיחת השער. |
| **3. אישור כניסה** | מזכיר הקלפי | כשהנורה דולקת ומופיעה הודעת `VOTER WAITING`, ודאו שהקלפי פנויה ולחצו פעם אחת על כפתור האישור. |
| **4. מעבר בשער** | מצביע | המתינו לפתיחה מלאה של השער ועברו דרכו. השער מתחיל להיסגר אוטומטית 7 שניות לאחר סיום הפתיחה. |
| **5. יציאה** | מצביע | בסיום ההצבעה, התקרבו לשער מבפנים עד למרחק של 30 ס"מ או פחות מהחיישן האולטרסוני. כשהשער נפתח, עברו דרכו. גם ביציאה השער מתחיל להיסגר לאחר 7 שניות. |
| **6. בקשת סיוע** | כל מי שמשתמש במערכת | כוונו את השלט אל המקלט ולחצו על כפתור `1`. ודאו שמופיעה הודעת `HELP REQUESTED` ושהנורה מהבהבת. |
| **7. ביטול בקשת סיוע** | כל מי שמשתמש במערכת | לאחר קבלת הסיוע, או אם אין בו עוד צורך, כוונו את השלט אל המקלט ולחצו על כפתור `5`. |
